# Changelog

## 0.1.0 (2026-11-19)

First release.

- **A panel beside every Open and Save dialog,** in any app that uses the standard macOS dialogs, as sheets or windows.
- **Folders open in Finder,** front window first.
- **Favorites** you pin from the panel, the menu or a folder picker, which follow a folder if it's renamed or moved. Reorder and remove them in the window.
- **Recent folders:** ones you jumped to and the one open in Finder when a dialog appeared. Off and cleared with one click.
- **One click sends the dialog there,** through the dialog's own Go to Folder.
- **⌃⌥J steps through the folders,** and ⌃⌥⇧J goes back, registered only while a dialog is open.
- **iCloud Drive, external drives and network shares** named the way Finder names them, with drives that aren't connected shown as such.
- **Turn it off in any app,** or pause it everywhere.
- **Open at login**, on by default and easy to turn off.
- No entitlements, no network access, and Accessibility as its only permission.
